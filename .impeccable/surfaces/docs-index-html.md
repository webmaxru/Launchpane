# Homepage surface brief

## Scope and mode
Marketing homepage at `docs/index.html`; Persuade. Explain the native Mac app and send interested visitors to the standalone release or source.

## Audience and action
Mac users and technical operators who want to understand or manage background services. Help them recognize the service types Launchpane covers, see the diagnostic value, and open the release page.

## Proof and constraints
Use authentic native app captures and the documented service paths, state, configuration, logs, and permission boundaries. Use the current shipping logo. Standalone downloads are Developer ID signed and Apple notarized from v1.2.2; keep the App Store screenshot edition clear. Do not add unsupported performance, customer, pricing, or security claims.

## Direction and memorable moment
Extend the shipping indigo/mint/amber identity. Four labeled macOS service sources route into the real searchable inventory in the first viewport, meeting at an amber signal; follow with configuration, log evidence, ownership limits, and a release close.

## Unresolved decisions
None for this first release.
