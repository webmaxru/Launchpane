Launchpane 1.4.0 (202610242100) - remembered folder access

This update adds persistent access to folders explicitly chosen in NSOpenPanel.
The app saves app-scoped security-scoped bookmarks in its sandbox container,
resolves them on relaunch and balances security-scoped access with stop calls.
"Forget folders" removes saved bookmarks and releases the active scopes.
It does not request access to any unselected inventory root.

The previously removed network.server entitlement remains absent.
Launchpane never listens for incoming connections.
The app requests only com.apple.security.app-sandbox,
com.apple.security.network.client (required by the system WebKit web view
that renders the bundled UI; without it the sandboxed window is blank),
com.apple.security.files.user-selected.read-write (folders chosen in the
native Open panel) and com.apple.security.files.bookmarks.app-scope (so those
chosen folders are remembered across launches as app-scoped security-scoped
bookmarks). Launchpane itself makes no network requests.

The previously approved sandbox restrictions remain unchanged:
All temporary filesystem exceptions remain absent. The distribution signature
omits com.apple.security.get-task-allow entirely, not merely setting it false.
All bundled executable architectures are checked for the permitted entitlements.

There is no unsupported service control in this Store edition: there
are no Load, Run, Stop/Unload, Restart, Enable/Disable, Remove or Administrator
controls. Backend IPC rejects them too. The separate standalone distribution
retains service management; this Store app is independently useful for native
inventory, state/configuration/schedule inspection, selected logs and editing
personal LaunchAgent plists. It never downloads/installs/updates/unlocks another
edition. A factual edition note and optional GitHub documentation/source link
are present; the note says the fully functional standalone edition is a
separate download on GitHub with the source code, and that the Store app never
downloads or installs it. There is no payment or license flow.

No account, demo credentials, subscription or external service is required.
Choose "Choose folders..." and use Command-Shift-G in the native picker to
select ~/Library/LaunchAgents, /Library/LaunchAgents, /Library/LaunchDaemons,
/Applications or ~/Applications as needed. Only selected inventory roots are
shown. Select a log's containing folder for logs. Cancel changes nothing;
chosen folders are remembered across launches and can be cleared with
"Forget folders".

Inspect rows, search/filter, read details, schedules and logs, and view/copy
Terminal references. To exercise file editing safely, create a disposable
personal plist for /usr/bin/true with Run at Load and Keep Alive off and no
schedule; save and edit it, verify contents and refresh. Saving does not load
or start it. Removal is not a Store feature; clean up the disposable file in
Finder after the demonstration. Never change existing vendor services for QA.

All product data remains local. There are no analytics,
ads, payments, cloud services, regulated content or regional differences.

Local sandbox testing on macOS 12.7.6 verified choosing folders, quitting,
restoring inventory without another prompt, and Forget folders. Local previews
are not TestFlight evidence. Exact-build TestFlight verification and any
required current-macOS recording remain release gates; no earlier build's
QA or recording is claimed as evidence for 1.4.0.
