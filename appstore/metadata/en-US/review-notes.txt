Launchpane 1.3.1 replacement preparation - NOT YET READY FOR REVIEW

This candidate addresses the October 15 rejection of 1.2.1 (202610100953),
submission 9249e9ef-0e6c-4043-9197-2bb9e2053b49, guideline 2.4.5(i).

1. Entitlements

All temporary filesystem exceptions have been removed, including the rejected
LaunchAgents, LaunchDaemons, and Applications paths. The signing script now
omits com.apple.security.get-task-allow entirely, rather than setting it false
or allowing debugging. Source and signed executable entitlement validation
reject either value and any temporary exception.

2. Access and main flow

No account, subscription, registration, or remote service is required.
Choose "Choose folders..." to open the native macOS folder picker.
Use Command-Shift-G to select ~/Library/LaunchAgents, /Library/LaunchAgents,
/Library/LaunchDaemons, /Applications, or ~/Applications. Only selected
inventory roots are shown. For logs select the log's containing folder.
Canceling makes no changes. Access lasts until quit; select again on reopening.

Search/filter the inventory and select a row for configuration, state,
schedules, logs and command references. Shared agents and daemons remain
read-only; administrator access is unavailable. Login helpers permit only
Enable/Disable, with lifecycle controlled by the parent app. An optional
GitHub documentation/source link opens the browser; it does not download,
install, update or unlock another edition.

For safe write-flow QA, select the test user's Library/LaunchAgents folder,
create a disposable agent with executable /usr/bin/true, Run at Login off,
and Keep Alive off, save it, inspect it, then remove it and confirm cleanup.
Folder access does not confer launchd authorization: this complete flow must
pass in the exact signed candidate before submission.

3. Privacy and external services

Service definitions, state, logs, and configuration remain local. No analytics,
advertising, authentication, payments, cloud storage, or AI service is used.
The network client/server entitlements support the embedded Tauri/WebKit
runtime on supported macOS versions, not an external product service.
There are no regional feature differences or regulated content.

4. Outstanding evidence - submission hold

Local ad-hoc sandbox QA verified native folder consent, inventory, reopening,
and disposable agent creation. Loading that agent failed with bootstrap error
5 inside the sandbox, while the same valid plist loaded outside it. This
candidate is NOT ready for resubmission; user-selected folder access does not
resolve launchd control authorization. Preserve the hold pending Apple/DTS
clarification and a working exact-build lifecycle/create/remove flow.

Screenshots must be recaptured from the current Store edition; historical
