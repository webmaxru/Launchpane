Launchpane 1.4.0 (202610242100)

This update remembers folders explicitly selected by the user in the native
macOS Open panel. App-scoped security-scoped bookmarks are stored inside the
app's sandbox container and resolved on relaunch. Forget folders removes the
saved bookmarks and releases active access. No path-based permission bypass,
temporary filesystem exception or administrator access is added.

The new com.apple.security.files.bookmarks.app-scope entitlement is used only
for this persistent folder-access feature, following Apple's documented
security-scoped bookmark API. App Sandbox, user-selected file read/write and
network.client for the bundled WebKit UI remain in place. Network.server and
get-task-allow remain absent.

The Store edition remains independently useful for inventory, configuration
and schedule inspection, selected logs, and personal LaunchAgent plist editing.
It does not load, start, stop, enable, disable or remove services. Saving a
plist does not activate it.

The first-run card provides Choose folders and Retry. The edition notice
clarifies that the optional GitHub link hosts the source code and a separate
standalone download. The Store app never downloads, installs, updates,
purchases or unlocks another edition.

Local sandbox tests verified folder selection, quit/relaunch restoration and
Forget folders. These are not exact-build TestFlight or current-macOS recording
claims. The release checklist tracks those gates separately.
