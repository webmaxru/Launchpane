Hello App Review,

We removed com.apple.security.network.server in 1.3.4. Launchpane never
listens for incoming connections. The app now requests only App Sandbox,
com.apple.security.network.client (the system WebKit web view that renders the
bundled UI needs it; without it the sandboxed window is blank) and
user-selected file read/write for folders chosen in the native Open panel.
Launchpane itself makes no network requests. Our build verifier now rejects
any entitlement without documented, tested functionality.

The October 15, 2026 guideline 2.4.5(i) fixes remain in place. All temporary filesystem exceptions are removed, and the
distribution signature omits com.apple.security.get-task-allow entirely.
The source and final executable entitlements are checked for every architecture.

We also removed unsupported service-control operations instead of requesting
additional sandbox exceptions. This Store edition is an independently useful
native service inspector and personal LaunchAgent plist editor. It has no
Load, Run, Stop, Restart, Enable/Disable, Remove or Administrator actions.
Backend IPC rejects those operations as well.

On launch, choose inventory folders in the native macOS picker; Command-Shift-G
can reach Library folders. Only explicitly selected inventory roots are scanned.
Logs require selecting their containing folder. Grants last until quit and
must be given again on reopening. No account or external service is required.

Review can inspect/search/filter service state, configuration and schedules,
read selected logs, and create/edit a disposable personal LaunchAgent plist.
Saving only writes a configuration file; it does not activate/reload a service.
Clean up the disposable file using Finder. Shared/system configuration and
login helpers are inspection-only. No existing vendor service needs changing.

The UI factually notes that our separate standalone distribution supports
service management and administrator workflows. The optional GitHub link is
for project documentation/source; the Store app never downloads, installs,
updates, purchases or unlocks another edition.

Data stays local, with no collection, analytics, ads, payment or cloud services.
There are no regional differences or regulated content.

The submitted 1.3.4 build is verified through TestFlight before submission.
